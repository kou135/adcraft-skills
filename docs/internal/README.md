# Internal Docs

These documents were authored during the initial MVP development of adcraft
and are kept for historical reference.

- [`specification.md`](./specification.md) — initial spec including
  goals, dependencies, scope decisions, and MVP completion criteria.
- [`structure.md`](./structure.md) — directory layout, file schemas,
  license file specs, system requirements.
- [`tasks.md`](./tasks.md) — phase-by-phase implementation plan that
  was followed to build v0.1.0, plus the visual-verification feasibility
  test log.

These are **not** part of the user-facing documentation. End users should
read the top-level [`README.md`](../../README.md) and the guides in
[`../`](../).

If you are reviewing or evolving the design, start here. If you are using
adcraft, you can ignore this directory.
