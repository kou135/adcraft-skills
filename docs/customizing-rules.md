# 不変ルールのカスタマイズ

`rules/create-advertisement-rules.md` は Skill B（`create-advertisement`）が**実行のたびに最初に読み込む**不変ルールです。生成される動画の品質と一貫性を担保する役割があります。

Skill C を使う場合は **`rules/create-advertisement-with-higgsfield-rules.md`** が同様の役割を持ちます（R-H1〜R-H17、v1.1.0）。本ドキュメントの考え方は両ルールセットに適用できます。

## いつカスタマイズするか

以下のような場合：

- ブランドガイドラインで「動画長は 15 秒固定」「特定のアスペクト比のみ」等の制約がある
- 自社用に特定のシーン構成テンプレートを強制したい
- 自社で禁止されている表現や使えない素材がある
- 既存の絵作りトーンを Skill に学習させたい

## カスタマイズ方法

### 方法 1：直接編集

`rules/create-advertisement-rules.md` を直接編集します。`R1`〜`R12` のルール番号は維持しつつ、内容を書き換えるか追加します。

例：「動画長を 15 秒固定にしたい」場合、R1 を以下のように変更：

```diff
- ### R1. 動画長
- - 1 本あたり **20〜30 秒**（…）
+ ### R1. 動画長
+ - 1 本あたり **15 秒固定**（変更不可）
```

### 方法 2：フォーク

会社全体で別のルールセットを使いたい場合、`rules/` を別ファイルにフォーク：

```
rules/
├── create-advertisement-rules.md         # OSS デフォルト（変更しない）
└── create-advertisement-rules.local.md   # 社内用
```

`skills/create-advertisement/SKILL.md` 内の参照を `local.md` に変えれば、社内ルールが優先されます。

## バージョン管理

`rules/create-advertisement-rules.md` の冒頭にバージョン番号があります（例: `v1.0.0`）。
カスタマイズするときはバージョンを上げ、`manifest.json.rules_version` がその値で上書きされることを確認してください。生成された動画がどのルール版に従ったか追跡できます。

## 推奨：変えてはいけないルール

以下は安易に外さないことを推奨：

- **R10. 配信は責務外**：これを外すと Skill が肥大化し、メンテナンス困難になります。配信は別 Skill で実装する設計に従ってください。
- **R5. バリエーション要件**：5 本同じ動画になると広告効果が落ちます。
- **R6. 着手前リサーチ**：これがないと表層的な動画になりがちです。
- **R8. 修正ループ上限**：上限なしにすると無限ループの危険があります。

## カスタマイズ後の確認

ルールを変更したら：

1. `examples/product-sample` で 1 本だけ生成テスト
2. 出力動画が新ルールに従っているか目視確認
3. `manifest.json.rules_version` が新バージョンになっていることを確認

問題なければ通常運用へ移行できます。
