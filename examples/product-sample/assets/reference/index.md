> 対応表を実画面に合わせて書き換える。

ソース: （TaskFlow は架空のプロダクト。実例として `examples/product-sample/components/` の

## 1. プロダクト概要

TaskFlow は複数プロジェクトを抱えるフリーランス向けの軽量タスク管理 SaaS。
ブラウザのみで動き、Notion ライクな軽さで 1 ボードに全タスクを集約できる。

- **テーマ**: ライトモード（白〜淡グレー、アクセントは緑系）
- **タイポ**: 英語 = sans-serif（Inter）、UI 日本語 = Noto Sans JP
- **ステート分岐**: 認証状態 / プロジェクト数 / 当日タスク完了率

## 3. 画面 × 対応写真の対応表（雛形）

### A. ダッシュボード（DashboardScreen / `/dashboard`）

- **役割**: 起動直後のメイン画面。全タスクが 1 画面に並ぶ
- **状態分岐**:
  - 通常状態: タスクが時系列で並ぶ
  - 空状態: 「最初のタスクを追加」CTA
- **UI**: 上部に検索バー、左サイドバーにプロジェクト一覧、中央にタスクリスト
- **対応写真**:
  - 通常状態: `dashboard.png`
  - 空状態: `dashboard-empty.png`

### B. タスク追加モーダル（TaskAddModal）

- **役割**: タスク作成のミニフォーム。30 秒で完了する設計
- **UI**: タイトル、日付、プロジェクト選択、保存ボタン
- **対応写真**: `task-add-modal.png`

### C. プロジェクト一覧（ProjectsScreen / `/projects`）

- **役割**: 全プロジェクトの俯瞰、絞り込み
- **UI**: プロジェクトカードのグリッド、各カードに進捗バー
- **対応写真**: `projects.png`

### D. 設定画面（SettingsScreen / `/settings`）

- **役割**: 通知設定、アカウント情報、エクスポート
- **UI**: 縦並びリスト形式の設定項目
- **対応写真**: `settings.png`

## 5. 広告制作での参照ガイド

### voice-spec のカテゴリと推奨参照画像

| voice-spec category | 参照しやすい画面 | 理由 |
|---|---|---|
| `worldview`（世界観訴求） | デスク / ノートパソコン / コーヒー (生活シーン) | 暗めではなく明るい朝の生活感が世界観表現に適合 |
| `feature`（機能訴求） | `dashboard.png` / `task-add-modal.png` | 操作の "before/after" を見せやすい |
| `persona`（ペルソナ pain 訴求） | `dashboard-empty.png` + `dashboard.png` | カオス → 整理の対比 |

### 用語の注意

- **ボード**（UI 内部用語）: 広告では「1 画面」「タスクリスト」と日本語訳
- **プロジェクト**: 広告では「案件」と訳すと顧客像（フリーランス）に響きやすい

### 避けたい誤用

- 競合実名（Notion / Asana / Trello / Jira / Linear / ClickUp 等）
- 「業務効率化」「DX」「タイパ」等の流行語
- 大企業向けの "team collaboration" 訴求（TaskFlow は個人〜小規模）

## 6. 自分のプロダクト用に書き換える手順

1. このファイルをコピー: `cp examples/product-sample/assets/reference/index.md products/<your-name>/assets/reference/index.md`
2. 実プロダクトの画面スクリーンショットを `products/<your-name>/assets/reference/` に配置
3. 「画面 × 対応写真の対応表」を実画面に合わせて書き換え
4. 「広告制作での参照ガイド」の category マッピングを実画面に合わせる
5. Skill C が起動時にこのファイルを読んで対応画像を参照する
